🎯 Lead Finder — Turso + Plunk

Store extracted leads in a Turso database and verify email addresses with Plunk. The Leads tab in the side panel hunts sites, categorizes contacts with your AI key, saves them to Turso, and validates emails via Plunk.

Create one free at turso.tech (or run your own libsql server).

🧩 Plugins

Attach plugins to extend the Lead Finder — no coding needed. A plugin is a .json file that can add AI agent tools (e.g. job-board lookups, custom APIs), send every new lead to a webhook, add interest/category rules, and add export formats. Get plugin files from your team, a marketplace, or write your own — see the format.

🤖 Generate a plugin with AI

Describe what you want in plain language and the AI writes the plugin JSON for you. Review it, then install — no coding needed.

About

Powered by Spider Cloud — the fastest web crawler and scraper, built in Rust. Open source at github.com/spider-rs/spider.

BYOK keys are stored via chrome.storage.sync and never sent to Spider servers. AI calls go directly to the provider's API from your browser.
